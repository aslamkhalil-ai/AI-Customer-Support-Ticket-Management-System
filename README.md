# AI Customer Support & Ticket Management System

An AI-powered customer support automation system built using **n8n, OpenAI, Google Sheets, and Gmail**.

## Overview

This project automates customer support operations by analyzing incoming customer messages, identifying their intent and sentiment, assigning priority levels, and generating relevant responses using AI.

The system can automatically respond to customers or escalate complex and sensitive cases to human support.

## Key Features

- Automated customer inquiry intake through Webhooks
- AI-powered message analysis using OpenAI
- Customer intent and sentiment detection
- Automatic ticket priority classification
- FAQ-based customer response generation
- Human support escalation
- Ticket logging and management using Google Sheets
- Automated error notifications through Gmail

## Technology Stack

- n8n
- OpenAI
- Google Sheets
- Gmail
- Webhooks
- JavaScript
